# Contributing to CoHive

Thank you for your interest in **CoHive**!

## Maintenance & Contribution Policy

This repository is primarily maintained for source code transparency and public distribution. Due to limited maintenance capacity:

* 🚫 **Pull Requests & Feature Requests**: We are **not** actively accepting pull requests or feature requests at this time.
* 🐛 **Bug Reports & Security Disclosures**: We welcome bug reports and security vulnerability disclosures via GitHub Issues or GitHub Security Advisories.

Thank you for your understanding!
